# Exercícios — Prompt Challenges

## Como fazer
Para cada desafio, escreva um prompt e teste com o `tutor-ia` ou com uma API de LLM diretamente. Depois refine até o resultado ficar satisfatório.

## Nível 1 — Iniciante

### 1.1 — Explicação Simples
Crie um prompt que faça o modelo explicar "o que é uma variável" para uma criança de 10 anos.

### 1.2 — Geração de Código
Crie um prompt para gerar uma função que valide um email em JavaScript.

### 1.3 — Formatação
Crie um prompt que peça uma lista de 5 dicas de CSS em formato JSON.

## Nível 2 — Intermediário

### 2.1 — Prompt com Contexto
Crie um prompt para um assistente que ajuda a escrever commits semânticos. Inclua: exemplos de commits, regras de convenção, e formato de saída.

### 2.2 — Few-shot
Crie um prompt que ensine o modelo a classificar sentimentos (positivo/neutro/negativo) com 3 exemplos.

### 2.3 — Chain-of-Thought
Crie um prompt que faça o modelo resolver um problema de lógica passo a passo.

## Nível 3 — Avançado

### 3.1 — System Prompt Completo
Escreva um system prompt para um "code reviewer automático" que analisa código JavaScript e retorna: segurança, performance, boas práticas, sugestões.

### 3.2 — Prompt para Agente
Crie os prompts (system + tools) para um agente que responde perguntas sobre um repositório GitHub.
