# Projeto 04 — Projeto Final

## Descrição
Projeto livre que consolida todos os conhecimentos do curso. O tema é de escolha do aluno, mas deve obrigatoriamente utilizar IA/agentes como parte do processo de desenvolvimento.

## Ideias Base

| Projeto | Descrição |
|---------|-----------|
| **Buscador de Repositórios** | Busca repositórios do GitHub por termo, com agente que sugere projetos similares |
| **Previsão do Tempo** | Clima com geolocalização, agente sugere atividades baseado no clima |
| **Tradutor com Contexto** | Tradução + agente que explica expressões idiomáticas |
| **Gerador de Quizzes** | Quiz com perguntas geradas por IA sobre qualquer tema |
| **Diário com IA** | Diário pessoal onde a IA analisa sentimentos e sugere reflexões |

## Requisitos Mínimos
- [ ] Interface web (HTML/CSS/JS) responsiva
- [ ] Interatividade com o usuário
- [ ] Consumo de pelo menos uma API externa
- [ ] Funcionalidade que utiliza IA (LLM)
- [ ] Código organizado em módulos/arquivos
- [ ] Publicado no GitHub Pages

## Processo Recomendado
1. Defina o tema e valide com o `professor`
2. Escreva a especificação detalhada
3. Implemente com ajuda do `tutor-js` e `tutor-ia`
4. Revise com o `revisor`
5. Publish no GitHub Pages

## Critérios de Avaliação
- **Completude** (funciona sem bugs críticos)
- **Organização** (código limpo e modular)
- **UX** (interface agradável e responsiva)
- **Uso de IA** (integração bem feita, prompts bem escritos)
- **Documentação** (README explicando o projeto e como usar)
