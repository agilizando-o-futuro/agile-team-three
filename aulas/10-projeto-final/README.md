# Aula 05 — Projeto Final

## Objetivo
Desenvolver uma aplicação completa utilizando IA e agentes como ferramentas de apoio durante todo o ciclo de desenvolvimento.

## Especificação Geral

Crie uma aplicação web com HTML, CSS e JavaScript que resolva um problema real. A aplicação deve:

- Ter interface responsiva (CSS)
- Ter interatividade com o usuário (JS/DOM)
- Utilizar uma API externa (via fetch)
- Ser organizada em arquivos separados
- Ter código revisado por pares e por IA

## Sugestões de Projetos

| Projeto | Descrição |
|---------|-----------|
| **Buscador de Repositórios** | Busca repositórios do GitHub por termo |
| **Previsão do Tempo** | Usa API de clima com geolocalização |
| **Tradutor Simples** | Interface para API de tradução |
| **Gerador de Quizzes** | Quiz temático com perguntas geradas por IA |

## Processo

1. **Planejamento** — Use o `professor` para refinar a ideia
2. **Spec** — Escreva a especificação detalhada
3. **Implementação** — Use o `tutor-js` para tirar dúvidas
4. **Revisão** — Submeta para o `revisor`
5. **Refinamento** — Itere com base no feedback
6. **Entrega** — Publique no GitHub Pages

## Critérios de Avaliação

- Organização do código (separação de arquivos)
- Funcionalidade completa (sem bugs críticos)
- UI/UX (usabilidade e responsividade)
- Uso adequado de IA (evidência de prompts usados)
- Documentação (README do projeto)
